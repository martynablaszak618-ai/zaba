# Zrzuty ekranu do dokumentacji projektu

Umieść tutaj zrzuty ekranu przed prezentacją na zajęciach.

## Wymagane pliki

| Nazwa pliku | Zawartość |
|---|---|
| `01_menu.png` | Menu główne |
| `02_rozgrywka_latwy.png` | Gra — poziom łatwy |
| `03_rozgrywka_sredni.png` | Gra — poziom średni |
| `04_wygrana.png` | Ekran wygranej |
| `05_przegrana.png` | Ekran przegranej |
| `06_testy.png` lub `wynik_testow.txt` | Wynik testów automatycznych |

## Jak zrobić

1. Uruchom grę: `./build/zaba_na_ulicy`
2. Na macOS: `Cmd + Shift + 4` i zaznacz okno
3. Zapisz pliki w tym folderze

Po dodaniu zrzutów możesz wstawić je do `docs/DOKUMENTACJA_OPISOWA.md` w sekcji 8.
